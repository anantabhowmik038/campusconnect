# CampusConnect
### Campus Event & Club Management System

**Course:** CSE451 — Software Engineering  
**Project Type:** Full-Stack Web Application  
**Development Team:** 4 Members  
**Target Completion Date:** November 24, 2026

## Project Overview

CampusConnect is a web-based platform designed to simplify campus event organization, club management, student participation, venue booking, attendance tracking, and campus communication.

The system provides role-based access for students, club officers, and campus administrators.

1. Create a feature branch.
2. Implement the assigned feature.
3. Commit changes with meaningful commit messages.
4. Push the branch to GitHub.
5. Open a Pull Request.
6. Perform peer code review and testing.
7. Merge approved changes into the main branch.
